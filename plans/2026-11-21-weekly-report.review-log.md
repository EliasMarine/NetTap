## Round 1 - Codex

Three issues block approval at `ba4a3178`. An upgrade can start emailing household activity that an owner never selected. A crash after SMTP acceptance can send the same report twice. And `get_smart_alerts(limit=5)` can process up to 500,000 groups on the G11. The proposed tests can pass with all three defects present.
