Connection State Reference
Established

Normal connection termination. Both sides sent FIN packets (or UDP exchange completed). This is the expected end state for healthy connections.
REJ
Connection was actively refused by the destination. Typically means the target port is closed or a firewall sent a RST (reset) packet.
S0
Connection attempt with no response. A SYN was sent but no SYN-ACK came back. Often indicates the host is down, unreachable, or being filtered.
